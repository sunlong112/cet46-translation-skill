# 六级翻译评分档位（15 分制）

> 目标：稳定命中 **10–12 分档**。这一档不奖励高级词汇，只要求「意思对、话通顺、错误少」。

## 档位对照

| 档位 | 分数 | 特征 |
|---|---|---|
| 一档 | 13–15 | 完整表达原文，用词贴切，行文流畅，仅个别小错，有明显语言亮点 |
| 二档 | 10–12 | **能表达原文大部分意思，用词基本准确，文字基本通顺，有少量语言错误** |
| 三档 | 7–9 | 勉强表达原文部分意思，用词欠准确，语言错误较多，影响理解 |
| 四档 | 4–6 | 仅译出个别片段，错误多，连贯性差 |
| 五档 | 1–3 | 几乎无法传达原文信息 |

## 10–12 分档的六个可操作标准

1. **信息完整**：每个意群都有对应译文，允许合句，不允许丢句。
2. **词汇基础**：以四级高频词为主，不堆砌六级词；错一个词不影响整体理解。
3. **句式朴素**：简单句 + 少量并列句；从句总数 ≤ 句数的 1/3。
4. **语法错误少**：主谓一致、时态、冠词、单复数基本正确；每 100 词不超过 2 处小错。
5. **连贯自然**：用 and / but / so / however / also 这类基础连接词，不用 in terms of、with regard to 之类的书面套语。
6. **不硬译**：四字词、成语、俗语译成平实意思，不逐字对应。

## 与 13–15 分档的差别

- 13–15 档需要亮点表达、精准搭配、地道句式；
- 10–12 档**不需要亮点**，只需要「不出错 + 说清楚」。
- 因此不要为了加分强行使用高级词或长难句——那是扣分的主要来源。

## 常见扣分原因（按频次排序）

1. 主谓不一致（people is / he have）
2. 时态混用（一段里过去时、现在时来回跳）
3. 无主句不补主语（"With the development of..." 后面没主语）
4. 中文标点、中文语序残留
5. 专有名词、数字漏译
6. 成语逐字直译
7. 定语从句套定语从句
8. 一句话塞三个信息点，读到一半断气

## 自评句式

```text
【自评】六级 10–12 分档｜替换难词 X 处｜最长句 Y 词｜语法错误 Z 处
```
